# بوت أخبار ديسكورد 🎬

بوت ينزل أخبار **أنمي / مانجا / ألعاب / أفلام** في أربع قنوات ديسكورد، مترجمة للعربي،
ويشتغل لحاله من **GitHub Actions** كل 30 دقيقة (ما يحتاج سيرفر).

---

## كيف يشتغل

1. GitHub Actions يشغّل البوت مرة وحدة (`RUN_ONCE=1`) كل 30 دقيقة.
2. البوت يقرأ RSSات من مصادر كل قسم، يفلتر، يترجم، ويرسل للقناة المناسبة.
3. بعد التشغيل، البوت يحفظ قائمة الأخبار المرسلة في `seen.json` ويرفعها على GitHub
   (عشان ما يكرر نفس الخبر في التشغيل الجاي).

---

## فلاتر الأخبار (3 طبقات)

| الطبقة | الوصف |
|---|---|
| **أساسي** | إصدارات، إعلانات، مواعيد، تريلرات، DLC، تكاملات — ينزل أول بأول |
| **جانبي** | تقييمات و"الأفضل" — ينزل بس إذا القناة ساكتة ساعة+، وحدود يومية |
| **ممنوع** | أخبار الممثلين، الحياة الشخصية، الترويج، الإشاعات، الحرق، المقالات الشخصية |

الطبقة التالتة (الممنوع) فيها فلاتر جاهزة للأخبار التافهة، وتقدر تعطّل أي مجموعة منها من `config.json`.

## الأولويات والحدود

**الخبر الرئيسي هو الأهم دائماً** — ما ينزل خبر جانبي إلا إذا ما فيه أي خبر رئيسي في نفس القناة.

| القاعدة | الافتراضي | وين تعدّلها |
|---|---|---|
| أخبار رئيسية لكل قناة في التشغيل | 3 | `max_per_category_per_run` |
| أخبار رئيسية لكل تشغيل (كل القنوات) | 15 | `max_total_per_run` |
| أخبار جانبية لكل ساعة | 2 | `side_max_per_hour` |
| فاصل بين خبرين جانبيين | 60 دقيقة | `side_min_gap_minutes` |
| أخبار جانبية لكل قناة في اليوم | 4 | `RELAXED_PER_DAY` (متغير بيئة) |
| سكون القناة قبل الخبر الجانبي | 60 دقيقة | `QUIET_MINUTES` (متغير بيئة) |

> الأرقام فوق في `config.json`. إذا زاد عدد الأخبار وتبي تنزل أكثر، ارفع `max_total_per_run`.


## الأهم: كيف تحجب خبر ما تبيه؟

### الطريقة السهلة: تفاعل على الخبر
اعمل reacts على أي خبر ما يعجبك بـ **❌** (أو 👎 أو 🚫).
في التشغيل الجاي (أقل من 30 دقيقة):
- البوت **يحذف** الخبر من القناة.
- يسجّله في `blocklist.json` → **ما ينزل أبداً** (حتى لو نفس الخبر نزل من مصدر ثاني).

> يحتاج البوت صلاحية **Manage Messages** في القنوات عشان يحذف، و **Read Message History**
> عشان يقرأ التفاعلات.

### الطريقة اليدوية: `config.json`
عدّل `config.json` من GitHub (Add file → Edit) وخلك تكتب:

```json
{
  "blocked_words": ["gacha", "mobile game"],
  "blocked_titles": ["عنوان خبر محدد بالضبط"],
  "blocked_domains": ["site-annoying.com"]
}
```

وتقدر تفعّل/تعطّل مجموعات الفلترة التافهة:

```json
{
  "noise_groups": {
    "rumors": true,     // إشاعات وتكهنات
    "opinions": true,   // آراء ومقالات تحليل
    "questions": true,  // أسئلة وقوائم
    "promos": true,     // محتوى ترويجي ومسابقات
    "spoilers": true,   // حرق
    "personal": true,   // مقالات شخصية ومعلومات ما تهم
    "features": true    // مقالات ومواضيع (مو خبر): "The History of...", "How X changed..."
  }
}
```

## فحص الأهمية بالذكاء الاصطناعي (اختياري)

تقدر تشغّل Claude يقرأ كل خبر قبل ما ينزل، يحكم إذا مهم ويرجمه:
أضف **Secret** اسمه `ANTHROPIC_API_KEY`، وSecret `LLM_CHECK` قيمته `1`.

> ⚠️ يكلّف فلوس (طلب لكل خبر مرشح). من غير المفتاح، البوت يشتغل بالقواعد العادية.

---

## التشغيل محلياً

```bash
pip install -r requirements.txt
python news_bot.py          # يشتغل ويستمر يفحص كل 30 دقيقة
```

أو في وضع "تجربة" (يطبع بس ما يرسل):

```bash
RUN_ONCE=1 DRY_RUN=1 python news_bot.py
```

الإعدادات المحلية (غير Secrets) في `settings.py` — وهو **مستثنى من GitHub** (شوف `.gitignore`):

```python
DISCORD_TOKEN = "..."
ANIME_CHANNEL_ID = 123
MANGA_CHANNEL_ID = 123
GAMES_CHANNEL_ID = 123
MOVIES_CHANNEL_ID = 123
```

---

## الـ Secrets المطلوبة في GitHub

| الاسم | الوصف |
|---|---|
| `DISCORD_TOKEN` | توكن البوت (من Developer Portal) |
| `ANIME_CHANNEL_ID` / `MANGA_CHANNEL_ID` / `GAMES_CHANNEL_ID` / `MOVIES_CHANNEL_ID` | معرّفات القنوات |
| `LOG_CHANNEL_ID` | (اختياري) قناة تتلقى تنبيه لو فشل التشغيل |
| `ANTHROPIC_API_KEY` | (اختياري) لتفعيل فحص الأهمية بالذكاء الاصطناعي |
| `LLM_CHECK` | (اختياري) `1` لتفعيل الفحص |

### صلاحيات البوت في ديسكورد
- `Send Messages`, `Embed Links`, `Attach Files`
- `Read Message History` (لمنع التكرار + قراءة التفاعلات)
- `Manage Messages` (اختياري: لحذف الأخبار اللي تعلّمها)
